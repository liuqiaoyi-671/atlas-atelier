# Atlas Atelier

一个在浏览器本地运行的分层场景排版编辑器：把背景、建筑、地形和物件放入画布，通过拖动、缩放与旋转调整构图。

这是个人视觉探索过程中，与 AI 协作迭代的工具原型。仓库提供编辑器源码和一个可运行的插画地图示例，示例素材包含 AI 生成插画与人工编排。这里的地图用于展示排版能力，不代表真实地理数据或当前个人网站的导航。

## 本地运行

无需安装前端依赖。在本目录开启任意静态 HTTP 服务，例如：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8080/`。请通过 HTTP 服务访问，直接双击 HTML 无法读取示例 JSON。

## 已有功能

- 选择、拖动、缩放和旋转独立图层；方向键微调。
- 图层排序、隐藏、锁定、复制和删除。
- 撤销／重做；多个场景。
- 本地 IndexedDB 自动保存，同源窗口同步。
- 上传图片，导入／导出包含素材的项目 JSON。
- 场景预览与独立查看页。

布局与上传素材保存在当前浏览器；没有账号、远程数据库、在线 AI 调用或服务端上传接口。清理浏览器数据会删除本地保存，请用“导出完整项目”自行备份。

## 文件结构

- `index.html`、`editor.js`、`style.css`：编辑器界面和操作。
- `renderer.js`：共享场景渲染与项目格式验证。
- `seed-project.json`、`assets/`：精简示例与必要素材。
- `viewer.html`、`viewer.js`：导入场景后独立查看。
- `atlas-review.html`、`atlas-review.js`：示例全图与区域查看。
- `art-direction/`：两种早期画风探索示例。

本公开版本仅保留一个示例场景，并把原 PNG 素材转换为较轻的 WebP。历史导出、个人研究规划、内部记录和原工程备份未包含在仓库中。
